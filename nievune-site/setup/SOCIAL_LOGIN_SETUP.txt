NIEVUNE — SOCIAL LOGIN SETUP

GOOGLE (recommended now)
1. In Supabase: Authentication > Providers > Google.
2. Keep this page open to see the callback URL.
3. In Google Cloud, create an OAuth Client ID of type Web application.
4. Authorized JavaScript origin:
   https://beladesign.github.io
5. Authorized redirect URI:
   https://hbwdvfzqxmoqdzirlwzn.supabase.co/auth/v1/callback
6. Copy the Google Client ID and Client Secret into the Google provider page in Supabase.
7. Enable the provider and save.

The site already has the Google button and calls Supabase OAuth.

APPLE (prepared but hidden)
The code is ready, but Apple login is hidden in config.js:
  socialAuth: { google: true, apple: false }

Apple requires an Apple Developer Program account and Apple-side configuration. After that setup, change apple to true.
